# AI SVG Benchmark：运行约束

本目录是一轮独立的 AI SVG 生成实验。请严格遵循以下规则。

## 工作范围

- 仅在当前目录及其子目录中创建或修改文件。
- 不要修改本文件 `AGENTS.md`。
- 不要读取或修改其他 `runs/` 目录。
- 不要覆盖或删除已有实验结果。
- 所有最终说明和报告使用中文。

## 实验模式

本轮实验模式为：

- 语言：纯中文提示词
- 模式：纯提示词
- Skill：禁止使用
- MCP：禁止使用
- 外部 AI 图像生成服务：禁止使用
- 在线 SVG 生成或矢量化 API：禁止使用
- 网络资源：禁止使用

可以使用当前环境中已有的本地工具、Python 标准库以及必要的本地渲染工具。

## SVG 生成规则

- 允许使用 Python 程序化生成 SVG。
- Python 只是生成工具，不是最终作品。
- 最终 SVG 必须是静态、完整、独立、自包含的文件。
- 删除所有 Python 脚本后，最终 SVG 仍必须能够直接在现代浏览器中打开。
- 不得使用 JavaScript 在浏览器运行时生成图形。
- 不得嵌入 PNG、JPEG、WebP、GIF、AVIF 或其他位图。
- 不得使用 `<image>`、`<foreignObject>`、Base64、`data:image` 或外部 URL。
- 不得先生成位图再自动描摹成 SVG。
- 不得通过空行、注释、不可见元素、画布外元素或完全相同的重复元素凑行数。
- 不得使用 `opacity="0"`、`display="none"` 或极小不可见图形凑复杂度。
- 所有随机生成必须使用固定种子，并保证结果可复现。
- SVG 应具有清晰的语义分组、图层名称和可读结构。

## 工程要求

必须实际执行以下过程：

1. 规划画面和图层。
2. 编写 SVG 生成器。
3. 生成最终 SVG。
4. 验证 XML、引用、禁用内容、元素数量和行数。
5. 将 SVG 实际渲染成 PNG。
6. 检查 PNG 预览中的构图和渲染错误。
7. 根据检查结果修改代码并重新生成。
8. 至少完成两轮“生成—验证—渲染—检查”。
9. 输出最终报告和真实统计数据。

不得只编写代码而不运行，也不得在没有证据时声称验证通过。

## 元数据要求

维护当前目录中的 `metadata.json`。

- 已知信息应如实填写。
- 无法确定的信息填写 `null`，不得猜测。
- 模型名称只能填写当前界面或运行环境明确显示的名称。
- 文件行数、大小、元素数量等数据必须通过程序或命令计算。
- 不得伪造验证结果。
- 任务结束时将状态设置为 `completed` 或 `failed`。
- 记录实际生成轮次、渲染轮次和已知问题。

## 最终文件

至少生成：

- `prompt.md`
- `generate_fuji.py`
- `validate_svg.py`
- `fuji.svg`
- `preview.png`
- `REPORT.md`

不要把生成结果放进临时目录或未说明的位置。
