# 海澜市城市与轨道交通规划说明

## 城市设定

海澜市（Hailan）是一座位于霁江入海口的虚构中国沿海一线城市，常住人口 2140 万，都市圈人口约 3180 万，建成区约 2680 平方公里。城市东西向展开明显，霁江自西向东穿城入澄湾，北岸形成崇安老城、望江 CBD 与东澄科技走廊，南岸形成南津金融文化副中心、南部滨海新城与临湾航空城。

## 历史层次

- 明清时期：崇安卫城位于霁江北岸中部偏西，保留崇安门、鼓楼西、文庙、旧城墙、仓前街等地名。

- 清末至民国：霁江下游北岸和云洲岛发展为商埠，形成临江码头、银行街、旧码头、云洲码头等近代港埠空间。

- 二十世纪工业化：西阜区沿铁路、货场和旧运河发展机械、纺织与车辆维修，现保留西阜机厂、双棉厂、铁西货场等站名。

- 近三十年：望江 CBD、南津金融文化副中心、东澄科技新城、临湾航空城、海堤滨海新城和港岛深水港分期建设，网络呈现多年代叠加的不规则性。

## 自然地理骨架

- 主河流：霁江（Jijiang River）自西向东穿越城市，在东部入澄湾，中心段较窄，入海口显著变宽。

- 支流：青溪河从青岚丘陵和青岚水库向东北汇入霁江。

- 江心岛：云洲岛位于中心城区附近，承载近代码头、文化设施和跨江换乘。

- 山水生态：西南部为岚屏山生态保护区与青岚水库，大学城沿丘陵和平原交界布局。

- 海岸与港口：东南部为海堤滨海新城、临湾国际机场和深水港，港岛区靠近深水岸线，和居住新城之间保留潮汐湿地缓冲。

## 城市级交通枢纽

- 民用机场：临湾国际机场、西岭机场。

- 主要铁路客运站：海澜总站、北苑高铁站、南湾铁路站、东澄站、北城火车站。

- 其他枢纽：港湾邮轮中心、南部客运站、西岭客运站。

## 线路规划

### L1 赤门线 / Chimen Line

- 类型：metro；状态：operational。

- 起终点：西阜机厂 - 云帆软件园。

- 服务区域：西阜工业区、崇安老城、望江 CBD、东澄科技新城。

- 主要换乘站：西阜机厂、崇安门、人民广场、临江码头、望江商务区、博物馆、东澄站、国际会展中心。

- 跨越主河：否。

- 设置理由：老城东西主轴，串联西阜工业更新片区、崇安老城、望江 CBD 与东澄科技走廊。

### L2 南北线 / Nanbei Line

- 类型：metro；状态：operational。

- 起终点：北苑高铁站 - 南部客运站。

- 服务区域：北苑新城、崇安老城、江心岛、南津副中心、海堤新城。

- 主要换乘站：北苑高铁站、松台公园、北城火车站、西牌楼、人民广场、中洲南、南江门、南津中心、南湾铁路站、海堤中央。

- 跨越主河：是。

- 设置理由：北苑居住新城至南部海堤的南北跨江骨干，服务老城、江心岛、南津副中心和南湾铁路站。

### L3 江岛线 / Jiangdao Line

- 类型：metro；状态：operational。

- 起终点：老西站 - 海湾客运站。

- 服务区域：霁江沿岸、近代港埠区、云洲岛、东湾片区。

- 主要换乘站：老西站、西河口、霁江公园、临江码头、云洲码头、云洲公园、中洲南、南岸剧院。

- 跨越主河：是。

- 设置理由：沿霁江两岸和云洲岛布置的近代港埠文化线，连接老码头、银行街、岛上公共空间与东湾客运片区。

### L4 核心环线 / Core Ring Line

- 类型：ring；状态：operational。

- 起终点：人民广场 - 人民广场。

- 服务区域：崇安老城、望江 CBD、南津副中心、云洲岛。

- 主要换乘站：人民广场、霁江公园、西津渡、南江门、河洲公园、云洲公园、南岸剧院、金融街、文化中心、博物馆。

- 跨越主河：是。

- 环线关系：首末站均为人民广场，形成闭合核心环。

- 设置理由：中心城区闭合环线，分流人民广场、老城、主铁路站、CBD 与南岸金融文化区之间的换乘压力。

### L5 青岚线 / Qinglan Line

- 类型：metro；状态：operational。

- 起终点：青岚水库 - 东澄书城。

- 服务区域：青岚大学城、西南丘陵、南江门、云洲岛、东澄研发区。

- 主要换乘站：青岚水库、青岚大学城、书院湖、西津渡、南江门、云洲东、望江东。

- 跨越主河：是。

- 设置理由：西南大学城与中心城区、东澄软件园的通勤线，沿丘陵边缘和江心岛通道进入 CBD 外围。

### L6 北苑金融线 / Beiyuan-Finance Line

- 类型：metro；状态：operational。

- 起终点：北苑高铁站 - 南苑路。

- 服务区域：北苑新城、崇安北部、南津金融区。

- 主要换乘站：北苑高铁站、北苑中心、松台公园、北城火车站、太平坊、金融街、南津中心。

- 跨越主河：是。

- 设置理由：北苑居住与医疗片区通往南津金融文化副中心的跨江通勤线。

### L7 东澄科创线 / Dongcheng Innovation Line

- 类型：metro；状态：operational。

- 起终点：东澄站 - 湾北。

- 服务区域：东澄科技新城、国际会展片区、湾北社区。

- 主要换乘站：东澄站、科技新城、国际会展中心。

- 跨越主河：否。

- 设置理由：东部科技新城内部骨干，串联药谷、软件谷、生物港、会展北和湾北生活区。

### L8 滨海线 / Binhai Line

- 类型：branch；状态：operational。

- 起终点：南湾铁路站 - 临湾国际机场。

- 服务区域：南湾铁路站、海堤新城、滨海新城、临湾航空城。

- 主要换乘站：南湾铁路站、海堤中央、滨海新城、临空商务区、临湾国际机场、机场二号航站楼。

- 跨越主河：否。

- 支线关系：在 临湾国际机场 分叉，包含航站楼支线、航空物流支线。

- 设置理由：南部滨海新城与临湾航空城的普通服务线，在机场处分出航站楼和航空物流两支。

### L9 西岭快线 / Xiling Express

- 类型：regional_express；状态：operational。

- 起终点：西岭卫星城 - 东澄软件园。

- 服务区域：西岭卫星城、西阜产业走廊、海澜总站、望江东。

- 主要换乘站：西岭卫星城、老西站、海澜总站、望江东。

- 跨越主河：否。

- 设置理由：西部卫星城经河谷快速进入海澜总站和望江东商务片区的市域快线。

### L10 机场快线 / Airport Express

- 类型：airport_express；状态：operational。

- 起终点：海澜总站 - 机场二号航站楼。

- 服务区域：海澜总站、望江 CBD、南津副中心、临湾航空城。

- 主要换乘站：海澜总站、望江商务区、南津中心、南湾铁路站、临空商务区、临湾国际机场、机场二号航站楼。

- 跨越主河：是。

- 设置理由：以较少停站连接海澜总站、望江 CBD、南津中心、南湾铁路站和临湾国际机场。

### L11 临港线 / Lingang Line

- 类型：commuter；状态：operational。

- 起终点：南湾货场 - 港务大厦。

- 服务区域：南湾货运区、保税物流园、深水港区。

- 主要换乘站：港湾邮轮中心、深水港。

- 跨越主河：否。

- 设置理由：南湾东部与深水港、保税物流、船坞和邮轮中心之间的港区通勤线。

### L12 工业更新线 / Industrial Renewal Line

- 类型：metro；状态：operational。

- 起终点：铁西货场 - 仓前街。

- 服务区域：西阜工业区、崇安老城北、旧铁路走廊。

- 主要换乘站：西阜货场、西阜机厂、崇安门、北仓门、太平坊、北城火车站、西河口。

- 跨越主河：否。

- 设置理由：沿旧铁路货场和纺织机械厂区布设，服务西阜传统工业区更新与老城北侧社区。

### L13 北环联络线 / North Arc Connector

- 类型：arc_connector；状态：operational。

- 起终点：西阜货场 - 湾北西。

- 服务区域：西阜北部、北苑新城、东澄北部。

- 主要换乘站：西阜货场、北苑高铁站、北苑中心、松台公园。

- 跨越主河：否。

- 设置理由：中心北侧半环，联络西阜货场、北苑高铁站、北部医疗教育片区和东澄北部。

### L14 云洲会展线 / Yunzhou-Expo Line

- 类型：metro；状态：operational。

- 起终点：国际会展中心 - 海洋公园。

- 服务区域：国际会展片区、云洲岛、南津金融区、滨海新城。

- 主要换乘站：国际会展中心、科技新城、望江东、博物馆、云洲码头、河洲公园、云洲东、金融街、文化中心、滨海新城。

- 跨越主河：是。

- 设置理由：从国际会展中心经望江东、云洲岛到南岸金融和滨海新城的跨江联络线。

### L15 青岚支线 / Qinglan Branch Line

- 类型：branch；状态：operational。

- 起终点：青岚大学城 - 梅岭口。

- 服务区域：青岚大学城、青岚生态区、西岭机场。

- 主要换乘站：青岚大学城、书院湖、青岚水库、西岭机场。

- 跨越主河：否。

- 支线关系：在 梅岭口 分叉，包含水库支线、西岭机场支线。

- 设置理由：大学城内部支线，在梅岭口分向青岚水库生态片区和西岭第二机场方向。

### L16 西北机场市域线 / Northwest Airport Regional

- 类型：regional_express；状态：operational。

- 起终点：西岭机场 - 北苑高铁站。

- 服务区域：西岭机场、西岭卫星城、北苑高铁站。

- 主要换乘站：西岭机场、西岭卫星城、北苑高铁站。

- 跨越主河：否。

- 设置理由：第二机场与西岭卫星城、北苑高铁站之间的市域快线，承担外围机场和城际换乘功能。

### L17 港岛支线 / Harbor Island Shuttle

- 类型：port_shuttle；状态：operational。

- 起终点：港湾邮轮中心 - 集装箱南。

- 服务区域：深水港、东港岛、海门岛。

- 主要换乘站：港湾邮轮中心、深水港。

- 跨越主河：否。

- 设置理由：深水港区内疏港支线，连接邮轮中心、航运大厦、东港岛和集装箱南端。

### L18 东岸线 / East Coast Line

- 类型：metro；状态：under_construction。

- 起终点：东澄站 - 东堤。

- 服务区域：东澄科技新城、东岸湿地、滨海新城、临湾航空城。

- 主要换乘站：东澄站、国际会展中心、滨海新城、临空商务区、临湾国际机场。

- 跨越主河：是。

- 设置理由：建设中的东岸跨江线，未来把东澄站、会展中心、滨海新城和临湾机场串联成东南走廊。
