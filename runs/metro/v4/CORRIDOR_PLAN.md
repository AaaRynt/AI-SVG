# 宁沧市城市轨道交通走廊规划

## 1. 走廊优先原则

本规划先确定公里级地理、城市级运输走廊和线路角色，再布置车站。`geography.json` 中的公里坐标用于验证相对方位和距离；它们不得被直接缩放后逐站连线。主图骨架必须将走廊转换成水平、垂直和 45° 方向，并在统一网格上形成稳定主轴。

走廊不是一条精确轨道中心线，而是可容纳一至多条平行线路的交通带。共走廊线路在主图中保持 10–16 px 平行间距，并在明确节点以 45° 或 90° 分流。支线共享段属于同一基础设施，不应被当成额外平行轨道制造视觉拥挤。

## 2. 城市走廊体系

### C01 老城东西主轴 / Old City East-West Trunk

- 类型：核心东西干线；北岸，不跨江。
- 地理走向：北皋南缘—宣津老城—人民广场—沧浦 CBD—海陵科技城。
- 使用服务：L1。
- 作用：承载最成熟的连续就业带，是全图最清楚的水平主轴之一。
- 制图要求：老城段保持近水平，向科技城只允许一次 45° 调整，不得画成长距离任意斜线。

### C02 核心南北主轴 / Core North-South Trunk

- 类型：核心南北干线；跨江。
- 地理走向：北原中心—宁沧北站—CBD—江心岛—南岸公共服务区—西部组团。
- 使用服务：L2。
- 作用：承担最大南北通勤流，并串联两个高铁节点。
- 制图要求：核心段近垂直，北端和滨海端以 45° 外展；不可穿过人民广场。

### C03 北岸沿江走廊 / North Riverside Corridor

- 类型：城市分配走廊；北岸沿江。
- 地理走向：石塘渡—老港埠—人民广场南缘—CBD 滨江—东部河口。
- 使用服务：L3。
- 作用：服务传统渡口、沿江商业与港埠更新区。
- 制图要求：以长水平段表现滨江连续性，在白鹭洲前清晰离开北岸。

### C04 白鹭洲跨江走廊 / Bailuzhou Cross-River Corridor

- 类型：江心岛跨江走廊。
- 地理走向：老城/港埠—白鹭洲—江南金融文化中心。
- 使用服务：L3、L10。
- 作用：为江心岛提供两条不同方向的轨道服务和过江冗余。
- 制图要求：两线在岛区可平行但不得完全重合；岛上换乘节点使用克制的白底符号。

### C05 CBD—南岸副中心走廊 / CBD-Southbank Center Corridor

- 类型：高容量跨江走廊带。
- 地理走向：CBD 多个分散节点—沧江—南岸金融、文化、传媒片区—南站方向。
- 使用服务：L2、L4、L7、L8、L13。
- 作用：容纳多个相邻但不共点的核心过江通道。
- 制图要求：线路在 `x=49–59 km` 的不同物理断面转换为示意图中的多条平行/错位通道，不得汇成一个五线巨型站。

### C06 北部新城通勤走廊 / Northern New City Commuter Corridor

- 类型：北部就业与居住通勤带。
- 地理走向：北皋—衡北—宁沧北站—海陵北缘。
- 使用服务：L2、L5、L8、L11、L14。
- 作用：把高铁、新城公共服务、产业和主城径向线组织到同一北部带。
- 制图要求：允许短段平行，随后按各自角色向南、东或西分流；不得反复互相穿越。

### C07 东部科技走廊 / Eastern Technology Corridor

- 类型：东部就业主轴。
- 地理走向：CBD 东缘—东澜中心—宁沧东站—会展—河口科研区。
- 使用服务：L1、L8、L11、L12、L15。
- 作用：连接成熟 CBD 与东部科技、会展和铁路就业节点。
- 制图要求：L1 形成主水平线；其他线路只在各自所需区段并行，必须清楚显示进入和离开走廊的分流点。

### C08 西南大学城走廊 / Southwest University Corridor

- 类型：教育科研通勤带；西侧跨江后沿青溪谷地。
- 地理走向：老城西部—青溪口—大学城体育中心—大学城中心—丘陵东缘。
- 使用服务：L5、L7、L9、L11、B2。
- 作用：组织多方向到校客流，并把所有线路限制在可建设谷地内。
- 生态约束：不得进入松月水库及其 1.8 km 轨道排除缓冲区。
- 制图要求：大学城内线路应形成清楚的主干与一条真实西支，不得画成校园内部网格。

### C09 南站—滨海新城走廊 / South Railway-Coastal New City Corridor

- 类型：南部沿海城市主轴。
- 地理走向：大学城东缘/南岸—宁沧南站—滨城新城—航空城西缘。
- 使用服务：L2、L7、L10、L12、L15、B2。
- 作用：连接南站、滨海住宅和南部公共文化设施。
- 制图要求：不同服务只共享必要区段；B2 从 L3 的雨湖节点进入本走廊，不与 L7 误画成同一支线族。

### C10 航空城普通地铁走廊 / Aerotropolis Local Metro Corridor

- 类型：机场普通地铁。
- 地理走向：宁沧站—CBD—南岸社区—航空物流与商务区—三座航站楼。
- 使用服务：L4。
- 作用：承担快线跳过的沿线居民与机场就业客流。
- 制图要求：机场段可使用较大示意站距，但不得像快线一样省略社区站；进站线路只到陆侧航站楼，不穿跑道。

### C11 国际机场快速走廊 / International Airport Express Corridor

- 类型：机场快线。
- 地理走向：北部居住中心—CBD—老城门户—国际机场。
- 使用服务：L13。
- 作用：连接高铁、核心商务与机场。
- 制图要求：以少停站、长区间和独立线型体现快线；不得绕行普通住宅区；最多 7 个主要折点。

### C12 西岭机场—卫星城市域走廊 / West Ridge Airport-Satellite City Regional Corridor

- 类型：市域快线。
- 地理走向：西岭机场—西岭卫星城—谷地铁路—工业更新区—老城—市政厅。
- 使用服务：L14。
- 作用：服务西部独立卫星城和第二机场。
- 生态约束：沿既有谷地、道路和铁路，不穿西山保护区与松月水库。
- 制图要求：外围区间使用 100–180 px 级示意站距，最多 8 个主要折点。

### C13 河口—港区通勤走廊 / Estuary-Port Commuter Corridor

- 类型：河口和港区通勤带。
- 地理走向：宁沧东站/会展—河口科研—潮平—青岚深水港。
- 使用服务：L12、B1。
- 作用：L12 服务科技城与河口就业；B1 从 L10 的潮平分叉后进入低密港口段。
- 制图要求：潮平是 L10/B1 必须可见的真实分叉；B1 进入港区后站距明显大于中心地铁。

### C14 铁路枢纽联络走廊 / Railway Hub Connector

- 类型：多中心铁路枢纽带。
- 地理走向：宁沧站—宁沧北站—宁沧东站—江南—宁沧南站的折线带。
- 使用服务：L8、L9、L13、L14。
- 作用：不同线路分别连接枢纽子集，不设置一条绕城“全收集”线路。
- 制图要求：该走廊是功能集合，不允许把所有使用线路画成一条长期共线；每条线仅占用与自身角色相符的区段。

### C15 核心环线走廊 / Core Ring Corridor

- 类型：闭合环线。
- 地理走向：宣津老城北—CBD 北—CBD 东—南岸东—南岸西—老城西—闭合。
- 使用服务：L6。
- 作用：在多个中型节点截获径向客流。
- 制图要求：骨架形成稳定八方向闭合轮廓；起点与终点同为南薰门但仅保留一个站记录；不得变成不闭合的螺旋。

### C16 外围半环联络走廊 / Outer Semicircle Connector

- 类型：开放半环。
- 地理走向：北皋—衡北—科技城—河口跨江—滨城—大学城。
- 使用服务：L11、L15。
- 作用：提供核心外部的组团互联；L15 只利用东半部并作为建设中分流线。
- 制图要求：半环必须明显开放，不能被误读为第二条环线；L11 保持连续大弧形骨架，L15 在科技城与河口区段以稳定间距并行后分离。

### C17 西北工业更新走廊 / Northwest Industrial Renewal Corridor

- 类型：工业更新通勤带。
- 地理走向：北货场—机厂路—宁沧站—老城北缘。
- 使用服务：L4、L9、L14。
- 作用：把保留就业、旧工业住宅和传统铁路站接入全网。
- 制图要求：保留清楚的西北—东南主方向，三线在不同节点分流，不长期完全重合。

### C18 南部滨海联络走廊 / Southern Coastal Connector

- 类型：南部东西向分配带。
- 地理走向：大学城—宁沧南站—滨城—螺汀湿地北缘—潮平。
- 使用服务：L7、L10、L11、L12、L15、B1。
- 作用：连接南部多个组团并为港区支线提供既有交通通道。
- 生态约束：普通线路保持在螺汀湿地西侧或北侧；B1 仅沿既有港口铁路穿过已开发边缘，不侵入湿地核心。
- 制图要求：南部线路以两个稳定水平层级展开，避免所有线路贴在同一海岸线上。

### C19 江心岛滨水走廊 / River Island Waterfront Corridor

- 类型：岛屿与南岸文化联络带。
- 地理走向：平码港埠—白鹭洲—江湾文化馆—传媒片区。
- 使用服务：L3、L10。
- 作用：组织岛上换乘并连接南岸文化设施。
- 制图要求：旧海关是二线换乘节点；两线进入和离开岛屿的方向必须不同，以便连续追踪。

## 4. 跨江断面控制

跨江线路按物理位置从西向东展开：

1. 老城西侧：L3、L9，示意图中错位表现。
2. 白鹭洲及岛侧：L2、L6、L7、L9、L15。
3. 核心东侧：L4、L8、L13，普通线与快线错位。
4. 东部河口：L10、L11。

主示意图不得把相邻物理断面折叠成同一点。跨江线之间应留出足够水平距离，使河流仍然是清楚的视觉骨架。

## 5. 核心换乘层级

- 全网 49 个二线换乘与 1 个三线换乘；唯一三线节点为宁沧高铁总站（L6/L11/L15）。
- 人民广场、中央商务区、市政厅、南浦金融城、江湾文化馆等保持分散的二线换乘，不共享同一坐标。
- L10/B1 在潮平、L3/B2 在雨湖形成真实分叉，分叉节点不单独制造普通换乘巨环。
- 环线在不同象限与径向线换乘，禁止通过把多条线塞进人民广场来减少交叉。

## 6. 骨架阶段否决规则

出现以下任一项，应退回走廊或骨架阶段重做：

1. L6 视觉上不闭合，或 L11 被误读成第二环线。
2. C01 与 C02 两条主轴不清楚。
3. 无标签图中无法从端点连续追踪任一服务。
4. C05 形成一个五线同站黑点。
5. 潮平或雨湖没有真实分叉几何。
6. B1 港区段出现中心城区级密集站距。
7. L13 绕行普通住宅，或与 L4 长距离完全重合。
8. L14 穿越山体、水库或生态保护区。
9. 非换乘交叉超过 25，或核心区超过 8。
10. 存在非八方向长线段、短距离锯齿或跨越半张画布的任意斜线。

骨架通过后才能按 `line_plan.json` 的站数和锁定锚点放置完整车站。
