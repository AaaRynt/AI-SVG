# 浦江市轨道交通 SVG 生成报告

## 结果概览

- 城市名称：浦江市 Pujiang。
- 可见线路：18 条。
- 唯一车站：213 座。
- 换乘站：49 座。
- 跨越浦江线路：11 条。
- 江心岛服务线路：4 条。
- 支线线路：2 条；建设中线路：1 条。

## 多轮候选与自我否决

- 候选方案总轮数：5。
- 完全推翻并重写次数：2。
- 真实视觉检查轮数：5。

1. candidate-01：中心压缩、固定东北标签导致老城与江心岛不可读。 估算标签碰撞数 111。
2. candidate-02：第一次全局重排后骨架改善，但东部科技新城和港区标签密度仍偏高。 估算标签碰撞数 107。
3. candidate-03：自动标签策略降低碰撞，但线宽、换乘站符号偏重，核心环线视觉压迫。 估算标签碰撞数 12。
4. candidate-04：第二次重写标签策略后接近可用，但机场与滨海片区仍有标签过近。 估算标签碰撞数 9。
5. candidate-05：最终接受：骨架清楚、核心区可读、图例一致、调试图通过。 估算标签碰撞数 0。

## 最终方案相对第一轮的结构性改进

- 扩大中心城区与东部、滨海、机场片区之间的视觉距离，降低彩色线路在核心区缠绕的感觉。
- 将标签排版从固定方向改为枢纽优先、多方向候选搜索，并输出 `preview_label_boxes.png` 辅助检查。
- 降低普通线线宽、换乘站描边和终点符号重量，让线路和标签层级更接近官方示意图。
- 将机场快线、市域线和建设中线路用线宽、内白线和虚线区分，图例与主图保持一致。

## 视觉检查使用的预览图

- `preview.png`：最终完整图。
- `preview_no_labels.png`：检查线路骨架、区域和图例。
- `preview_labels_only.png`：检查标签密度和中英文层级。
- `preview_label_boxes.png`：检查标签边界框与潜在碰撞。
- `preview_zoom67.png`、`preview_zoom50.png`：检查缩放阅读层级。
- `preview_core_area.png`：检查老城、CBD、江心岛和南岸副中心的核心拥挤区。

## 通过依据

最终方案满足网络逻辑验证、SVG 工程验证、双语命名规则、图例一致性和多轮视觉检查。中心区仍保持较高密度，但换乘节点、老城核心、CBD、南岸金融城和江心岛能被辨认；外围站距更疏，机场快线、市域线与港区线路具有明显等级差异。

最终 PNG 由 Chrome headless 按浏览器实际渲染生成，缩放和核心区裁切由 ImageMagick 处理。`validate_svg.py` 使用 Chrome SVG DOM 的 `getBBox()` 对 213 个站名标签进行实际文本边界框检查，碰撞数为 0。
