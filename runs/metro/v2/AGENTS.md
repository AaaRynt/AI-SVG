# 虚构一线城市轨道交通 SVG 生成实验

## 核心任务

自行设计一座具有真实历史层次、空间结构和产业分区的中国沿海一线城市，并为其创建一张专业、复杂、中英文双语的城市轨道交通线路图。

城市、行政区、线路和站点均为虚构内容，但必须尽可能接近真实中国超大城市的发展逻辑，不得像随意拼接的游戏地图。

你需要自行完成：

- 城市名称及其英文名称
- 城市发展历史
- 行政区和功能区名称
- 河流、海湾、岛屿和地形
- 所有轨道交通线路
- 所有站点的中英文名称
- 换乘关系
- 线路颜色和编号
- 城市地标和交通枢纽
- 最终 SVG 布局与视觉设计

不得使用真实城市的完整线路网络，也不得直接临摹任何现实城市的官方地铁图。

## 城市总体规模

这是一座中国沿海河口型超大城市，整体规模接近中国一线城市。

基础设定：

- 常住人口约 `1800–2400 万`
- 都市圈人口约 `2800–3500 万`
- 建成区面积约 `2200–3000 平方公里`
- 城市东西跨度明显大于南北跨度
- 中心城区密集，外围存在多个相对独立的新城和卫星城
- 城市发展时间跨越数百年
- 同时存在老城、传统商业区、工业区、现代中央商务区、大学城、科技新城、航空城、港口和生态保护区
- 轨道交通已经经过约 `30–40` 年建设
- 线路建设并非一次完成，因此网络应带有历史演化留下的不规则性

不要把整座城市设计成规则棋盘。不同年代建设的道路、城区和线路应当呈现不同形态。

## 自然地理骨架

城市位于一条大型河流入海口附近。

必须满足以下空间关系：

- 一条主河流自西向东穿过城市中部，最终流入东侧海湾。
- 主河宽度在中心城区较窄，在东部入海口逐渐变宽。
- 河流将核心城市分为北岸和南岸。
- 中心城区附近有一座较大的江心岛或河洲。
- 西部和西南部存在低山、丘陵、水库和生态保护区域。
- 中部和东部以冲积平原为主。
- 东南部具有海岸线、滩涂和部分填海新区。
- 东部海湾内可设置一至两座大型岛屿。
- 港口和临港工业区必须靠近深水海岸。
- 国际机场应位于东南或东部沿海平原，不得靠近老城区。
- 第二机场应位于城市另一侧的外围地区。
- 大学城不得与重化工业区相邻。
- 饮用水源、生态保护区不得安排大型工业园。
- 城市核心广场、老城和行政中心不得位于地图最边缘。

地图中至少标注：

- 主河流的中英文名称
- 一条重要支流
- 海湾名称
- 一座江心岛
- 一处湖泊或水库
- 海岸线
- 生态保护区或山地名称

## 城市历史层次

城市站名和城区形态需要反映不同历史阶段。

### 传统老城

位于主河北岸、中部偏西的位置，是城市最早形成的区域。

特征：

- 有旧城墙、城门、古街、传统市场、寺庙或历史街区遗存
- 路网不规则
- 街道和站名带有传统地名特征
- 不应出现大量“未来城”“智慧谷”等现代名称
- 轨道交通站距较短、换乘较密集
- 老城中央或邻近地区应存在一个城市级公共广场
- 主火车站或旧火车站可以位于老城北侧，但不能直接占据历史核心

### 近代商业与港埠区

位于主河下游北岸或江心岛周边。

特征：

- 历史码头、近代银行街、旧租界式商业建筑或沿江仓库
- 后期改造为文化、商业和旅游区域
- 站名可体现码头、街巷、桥梁、仓库和历史建筑
- 与现代 CBD 相邻，但不能完全混为一体

### 传统工业区

位于西北或北部外围，沿铁路和旧运河发展。

特征：

- 机械、钢铁、纺织、车辆制造、仓储和铁路货场
- 部分区域已经更新为创意园、住宅区或城市公园
- 仍保留工业遗址类地名
- 不得与大学城、风景区或高端金融中心直接混杂
- 应有货运铁路、物流园和老工业社区

### 现代中央商务区

位于主河北岸中部偏东，与老城保持一定距离。

特征：

- 高层办公、商业综合体、金融机构、城市级文化设施
- 有中央商务区、金融街、城市广场、博物馆或大剧院
- 至少有 `3–4` 条线路服务，但不要让所有线路都经过同一个站
- 商务区与人民广场或传统老城核心不能被视为同一个区域
- CBD 对岸可设置新的金融副中心

### 南岸金融和文化副中心

位于主河南岸，与 CBD 隔江相望。

特征：

- 金融机构、文化中心、传媒机构、滨江公园和高端住宅
- 通过多条跨江线路与北岸连接
- 可以有大型交通枢纽，但不应完全取代老城中心
- 站名应偏现代，但避免全部使用抽象科技词汇

### 西南大学城与科研区

位于城市西南部丘陵和平原交界处。

特征：

- 多所大学、研究机构、图书馆、体育中心和学生社区
- 邻近湖泊、山地或生态公园
- 不能靠近港口、炼化、钢铁等重工业区
- 至少有一条普通地铁和一条支线或市域线路服务
- 大学站名不得全都直接使用“大学一站、大学二站”
- 可包含真实感较强的院校、书院、校园道路和村镇旧地名

### 东部科技新城

位于城市东部、主河下游北侧。

特征：

- 软件产业、研发机构、生物医药、会展中心和新型居住区
- 有独立副中心和较新的规则路网
- 邻近国际会展中心
- 站距可以比老城稍大
- 站名应同时包含历史村镇名和现代功能名
- 不得所有站点都叫“科技园”“创新中心”“数字谷”

### 东南航空城

位于东南沿海平原。

特征：

- 国际机场
- 两座或三座航站楼
- 航空物流区
- 临空商务区
- 机场维修区
- 酒店和会展设施
- 至少有一条机场快线和一条普通地铁进入
- 机场快线应以较少停站方式连接 CBD 和主要铁路枢纽
- 普通线路服务沿途社区和航空城
- 机场不得位于城市中心

### 南部滨海新城

位于城市南部或东南沿海。

特征：

- 新住宅区、滨海商业、海洋公园、人工湖和文化设施
- 有部分填海区域
- 路网较规则
- 至少一条主线和一条支线服务
- 不得与深水港、集装箱码头和重化工业完全混在一起
- 可以与港区之间设置生态缓冲带

### 东部深水港和保税区

位于海湾外侧或东南远端海岸。

特征：

- 集装箱码头
- 保税物流园
- 港口铁路
- 船舶维修
- 仓储和临港工业
- 居住人口较少，站距较大
- 轨道线路以市域线、港区支线或通勤线为主
- 港区线路不得像中心城区地铁一样每隔很短距离设站
- 港口必须与海岸线空间一致

### 北部居住新城

位于城市北部。

特征：

- 大规模居住社区
- 医疗中心
- 区级行政中心
- 大型公园和商业中心
- 有一座高铁站或城际铁路站
- 至少两条轨道线路交会
- 不应被设计为只有住宅而没有就业和公共服务的睡城

### 西部生态和卫星城

位于西部丘陵之外或山谷平原。

特征：

- 独立卫星城
- 旅游、生态、轻工业和区域公共服务
- 与主城区之间距离较大
- 通过市域快线连接
- 普通地铁不应无意义地穿越大面积无人山区
- 线路应沿河谷、道路或城市走廊布置

## 城市级交通枢纽

至少设计：

- `2` 座民用机场
- `4` 座主要铁路客运站
- `1` 座老火车站
- `1` 座高速铁路总站
- `1` 座东部或南部铁路站
- `1` 座城际铁路枢纽
- `1` 个深水港客运或邮轮码头
- `1` 个长途汽车枢纽

枢纽空间关系必须合理：

- 高铁总站不能位于偏僻工业码头内部。
- 国际机场至少由两条轨道线路服务。
- 主要高铁站至少是三线换乘。
- 老火车站应靠近传统城区。
- 港口客运码头必须靠近海岸或大河下游。
- 第二机场可由市域线连接，但不能与主机场位于同一城市方向。

## 轨道交通规模

自行设计一套接近中国一线城市规模的网络。

最终应包含：

- `16–20` 条可见线路或运营服务
- `180–230` 个唯一车站
- `35–50` 个换乘站
- `1` 条核心环线
- `1` 条半环或弧形联络线
- `2` 条机场相关线路
- `1–2` 条市域快线
- `2` 条具有真实分叉关系的支线
- `1` 条建设中线路
- 至少 `6` 条线路跨越主河
- 至少 `2` 条线路经过江心岛
- 至少 `3` 条线路服务老城
- 至少 `3` 条线路服务现代 CBD 和南岸副中心
- 至少 `2` 条线路服务大学城
- 至少 `2` 条线路服务东部科技新城
- 至少 `2` 条线路进入滨海新城
- 至少 `1` 条线路进入深水港区

线路长度和站数必须有明显差异：

- 中心城区线路站距较密
- 郊区线路站距较疏
- 市域快线停站较少
- 机场快线不能像普通地铁一样站站停
- 港区线路不能在低人口区域设置大量密集车站

不得让所有线路都经过人民广场、中央车站或同一个换乘点。

一般换乘站应为两线换乘，少量为三线换乘，最多允许一至两个四线换乘站。不得大量制造四线、五线换乘站来简化布局。

## 线路规划逻辑

线路不能只是随机穿过地图。

每条线路必须具有明确功能，例如：

- 老城东西主轴
- 南北跨江主轴
- CBD 与机场快速联络
- 北部居住区通勤
- 大学城与中心城区连接
- 滨海新区联络
- 港区通勤
- 外围新城快速连接
- 环线换乘分流
- 铁路枢纽联络
- 东部科技走廊
- 西部工业更新走廊

创建 `CITY_PLAN.md`，逐条说明：

- 每条线路的定位
- 服务区域
- 起点和终点
- 主要换乘站
- 跨越的河流或地理障碍
- 普通线、快线、支线或建设中线路类型
- 为什么这条线路存在
- 它与其他线路的关系

线路不可出现：

- 没有服务任何人口或就业区域的绕行
- 为了填满地图而设置的无意义折返
- 机场快线绕行大量普通住宅区
- 环线未闭合
- 支线没有真实分叉节点
- 两条线路长期完全重合
- 跨河线路全部集中在同一位置
- 线路穿越水库、山体或机场跑道而没有合理说明

## 站点名称生成

所有站点名称均由你自行生成，但必须符合中国大城市真实命名习惯。

站名应混合以下来源：

- 历史地名
- 古街、城门、桥梁和坊巷
- 村镇和自然聚落名称
- 道路名称
- 河流、湖泊、山地和岛屿名称
- 行政和公共服务设施
- 商业中心
- 大学和科研机构
- 交通枢纽
- 工业遗址和港口设施
- 新城和功能区名称

建议大致比例：

- 历史地名、村镇和传统街区：`25%–35%`
- 道路、桥梁和方位地名：`20%–25%`
- 自然地理名称：`10%–15%`
- 公共设施和文化地标：`10%–15%`
- 交通枢纽：`5%–10%`
- 商务、科技和产业功能名称：不超过 `15%`

严格避免：

- 大量使用“未来城”“智慧谷”“创新港”“数字中心”“梦想小镇”等典型 AI 式名称
- 连续多个车站都使用同一种命名模板
- 大量站点全部以“路”或“大道”结尾
- 同一城市中重复或高度近似的站名
- 把人民广场、市民中心、中央商务区放在城市边缘
- 把大学城安排在炼化、钢铁或深水港工业区内部
- 把港口、码头、保税区放在内陆山地
- 把机场航站楼安排在老城中心
- 把历史城门、古寺和老街安排在全新的填海区
- 把重工业地名大量放入高端金融区
- 把所有新城区都命名为“新城”

站名应体现城市发展层次。例如：

- 老城区可出现城门、桥、巷、坊、寺、仓、渡口等历史语汇
- 工业更新区可保留机厂、纱厂、船坞、货场等旧称
- 大学城可出现校园、书院、湖泊、旧村和道路名
- 港区可出现码头、保税区、航运、船厂和港湾地名
- 郊区可保留镇、村、浜、塘、桥、湾、浦等地方名称
- 新商务区可使用广场、中心、金融街和文化设施名称，但数量应克制

## 中英文站名规则

所有站点必须同时提供中文和英文。

英文命名风格必须全图统一。

原则：

- 专有地名优先使用规范拼音。
- 具有明确公共功能的名称可采用英文意译。
- 火车站使用 `Railway Station`。
- 机场使用 `International Airport`、`Airport Terminal 1` 等规范表达。
- 大学、博物馆、会展中心、市民中心等公共设施可进行意译。
- 道路名称统一采用“拼音专名 + Road/Avenue/Street”或统一使用完整拼音，不得混用多套规则。
- 同一个中文通名必须保持同一种英文译法。
- 不得一部分站名使用拼音、一部分使用随意英文美化名称。
- 英文站名必须唯一，且与中文语义对应。

示例原则：

- 人民广场 → `People's Square`
- 市民中心 → `Civic Center`
- 国际会展中心 → `International Convention Center`
- 某专有历史地名 → 使用拼音
- 某铁路枢纽 → `XXX Railway Station`

创建 `NAMING_RULES.md`，记录实际采用的英文翻译规则和常见通名译法。

## 中间数据文件

在绘制 SVG 前，必须先创建：

```text
CITY_PLAN.md
NAMING_RULES.md
network.json
```

`network.json` 至少应包含：

- 城市名称
- 城市英文名称
- 行政区和功能区
- 河流、海湾、岛屿和海岸
- 线路编号
- 线路中英文名称
- 线路颜色
- 线路类型
- 每条线路的有序站点列表
- 每个站点的中文名称
- 每个站点的英文名称
- 所属区域
- 功能角色
- 换乘线路
- 是否为终点站
- 是否为交通枢纽
- 是否位于河流哪一侧
- 大致空间区域
- 线路建设状态

在 `network.json` 完成后先验证城市逻辑，再开始绘制 SVG。

不得为了方便绘图而在 SVG 生成阶段临时更改站名、删除站点或改变线路顺序。

## 城市逻辑自检

创建验证程序，对城市设定至少检查：

- 所有中文站名唯一
- 所有英文站名唯一
- 所有线路编号唯一
- 每条线路站点顺序完整
- 所有换乘关系对称一致
- 环线真实闭合
- 支线存在明确分叉站
- 国际机场至少有两条线路
- 主要高铁站至少为三线换乘
- 大学城不位于工业港区
- 深水港靠近海岸
- 人民广场或城市核心位于中心城区
- 老城不位于填海新区
- 机场不位于城市核心
- 至少六条线路跨越主河
- 建设中线路样式和状态一致
- 图例中的线路与实际线路完全一致

如发现城市空间或命名不合理，必须先修改 `network.json`，再生成最终 SVG。

## 地铁图视觉要求

最终线路图应接近现代中国大城市官方运营图的专业感，但不得复制任何真实城市的具体视觉系统。

建议画布：

```xml
viewBox="0 0 2400 1600"
```

视觉要求：

- 使用白色或极浅灰色背景
- 主河流和海湾使用低饱和浅蓝色
- 城市功能区使用非常浅的底色区分
- 每条线路具有清晰且可区分的颜色

### 强制视觉否决条件

出现以下任一情况，必须判定当前候选方案失败，继续生成，不得提交为最终结果：

#### 全局线路结构失败

- 线路整体呈现明显“彩色意大利面”状态
- 大量长距离斜线跨越整张图
- 线路方向杂乱，没有形成稳定的水平 / 垂直 / `45°` 组织
- 核心环线不清楚或视觉上不成环
- 支线看起来像独立乱入线路而不是主线分叉
- 跨河线路分布极不平衡，全部挤在少数位置
- 非换乘交叉过多，导致理解困难
- 主干线与支线没有清晰等级差异

#### 中心城区布局失败

- 中心城区过度拥挤
- 多条线路在极小范围内随意穿插
- 人民广场、CBD、老城核心或主要换乘站难以辨认
- 核心区没有形成“中心密、外围疏”的节奏
- 重要换乘站之间没有合理层次

#### 标签排版失败

- 中文站名明显重叠
- 英文站名明显重叠
- 中文与英文互相遮挡
- 标签与线路、站点或图例过近
- 标签虽然数学上不碰撞，但字号过小，普通观看不可读
- 中英文主次关系不清
- 英文成为噪点式极小文字，形式上存在但实际上不可用
- 核心区标签密集到无法正常阅读
- 标签过多使用引导线，导致视觉凌乱

#### 符号和图例失败

- 换乘站符号过大、过黑，压过线路本身
- 普通站、换乘站、终点站难以区分
- 图例与主图颜色、线型或符号不一致
- 图例可读性差，字号过小或结构混乱
- 建设中线路、机场快线、市域线与普通地铁缺乏清晰视觉差异

#### 城市空间逻辑失败

- 老城、CBD、大学城、港区、机场、会展中心等空间关系不可信
- 机场位于城市中心或老城区附近
- 大学城与重工业港区混杂
- 港区和码头不靠海岸
- 人民广场或市民中心位于地图边缘
- 功能分区底色与线路网络关系混乱，无法帮助理解城市结构
