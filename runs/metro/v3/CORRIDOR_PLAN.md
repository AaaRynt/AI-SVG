# 城市运输走廊规划

## 老城东西主轴 / Old City East-West Spine

- 类型：trunk
- 方向：horizontal
- 服务区域：靖安老城, 人民广场, 中央商务区, 东部科技新城
- 走廊容量：4 条左右
- 是否跨澜江：否

## 核心南北跨江主轴 / Core North-South River-Crossing Spine

- 类型：trunk
- 方向：vertical
- 服务区域：北川新城, 老城, 鹭洲, 南岸副中心, 滨海新城
- 走廊容量：3 条左右
- 是否跨澜江：是

## 沿江港埠走廊 / Riverfront Port-Commercial Corridor

- 类型：trunk
- 方向：horizontal
- 服务区域：旧码头, 鹭洲, 近代商埠, 会展中心, 海洲岛
- 走廊容量：3 条左右
- 是否跨澜江：是

## CBD—南岸副中心走廊 / CBD-South Bank Subcenter Corridor

- 类型：trunk
- 方向：diagonal
- 服务区域：中央商务区, 东平码头, 南岸金融城
- 走廊容量：3 条左右
- 是否跨澜江：是

## 北部新城通勤走廊 / Northern New Town Commuter Corridor

- 类型：commuter
- 方向：diagonal
- 服务区域：北川新城, 北部高铁站, 老城北缘, 南岸副中心
